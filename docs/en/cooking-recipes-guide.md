# 🍳 Oakhaven Culinary Compendium: 55 Global & Fantasy Recipes

> **Grounded Buff Rules:** Rowan holds up to **5 Active Buff Slots** simultaneously (`No Stat Stacking` — highest value wins; eating food when all 5 slots are full still restores HP/Stamina without overwriting active buffs). **Player-cooked dishes cap at 3 Buffs max** (`48 dishes with 0–2 buffs`, `7 pinnacle dishes with 3 buffs`). **5-Buff packages are EXCLUSIVELY sold by key NPCs.**
