### 🗄️ B. Dữ Liệu Cấu Trúc JSON (`docs/data/vi/` & `docs/data/en/`)
Hệ thống hiển thị trực quan tại `/database/<category>` được đọc trực tiếp từ các file JSON độc lập:
- **`characters.json`**: 51 nhân vật (40 NPC bản địa, 11 nhân vật đặc biệt/phương xa/trợ thủ).
- **`crops.json` & `trees.json`**: 41 loài thực vật (27 cây hoa màu theo mùa + 14 cây gỗ & ăn quả).
- **`recipes.json`**: 55 món ăn ấm nóng, nguyên liệu, trạm chế biến và buff thực chiến.
- **`monsters.json`**: 28 ma vật & 4 Boss Giám Ngục hầm mỏ 150 tầng, drops và hành vi AI.
- **`weapons.json`**: 23 vũ khí cận chiến & tầm xa theo 5 cấp quặng (Đồng $\rightarrow$ Void).
- **`items.json`**: Kho dữ liệu vật phẩm, hạt giống, quặng khoáng, món ăn, đạo cụ.
- **`quests.json` & `restoration_projects.json`**: Nhiệm vụ dân sinh, bounty săn quái và 12 dự án tái thiết.

## 🛠️ Hướng Dẫn Cài Đặt & Phát Triển

### Yêu Cầu Môi Trường
- **Node.js:** v18.0.0+ hoặc v20.0.0+
- **npm:** v9.0.0+

### Các Lệnh Thao Tác
```bash
# Cài đặt thư viện phụ thuộc
npm install

# Chạy server phát triển (Hot-reload)
npm run dev

# Biên dịch bản sản xuất (Production Build với Webpack)
npm run build

# Chạy server bản sản xuất
npm run start
```

> [!TIP]
> **Quy Chuẩn Tối Ưu Tốc Độ Cho AI Agent:**
> - Để tiết kiệm thời gian, **KHÔNG BẮT BUỘC** phải chạy lệnh `npm run build` sau mỗi lần chỉnh sửa tài liệu hoặc dữ liệu JSON. Chỉ cần đảm bảo cú pháp JSON và code JS/JSX sạch sẽ, hợp lệ; chỉ chạy build khi người dùng yêu cầu kiểm tra toàn diện.

## ⚖️ Quy Tắc Viết Nội Dung & Chống AI-Slop (Locked Canon)

Mọi đóng góp tài liệu và dữ liệu trên Wiki bắt buộc tuân thủ tiêu chí **Dark Cozy hậu chiến**:
1. **Grounded Writing:** Nhân vật mộc mạc, thực tế, có gai góc và tật xấu đời thường (lo toan cái ăn cái mặc, mái nhà dột, chuột cắn lúa, thấp khớp khi trời lạnh, nợ tiền quán).
2. **Cấm văn mẫu sáo rỗng & melodrama:** Tuyệt đối không dùng các cụm từ cảm xúc ước lệ, self-help hay triết lý giáo điều; bám sát sinh hoạt cơm áo gạo tiền và tâm lý thời hậu chiến.
3. **Cấm ý tưởng cũ đã hủy bỏ:** Tuyệt đối tuân thủ Locked Canon: Quán Ăn & Nhà Trọ The Hearth và hầm mỏ 150 tầng thuần Action RPG; không dùng các khái niệm quán trà phép thuật hay cơ chế ru ngủ quái đã loại bỏ.
